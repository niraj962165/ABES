Core Data & Roles

• Data Analyst: Interprets numbers and trends to create reports and dashboards using SQL and Excel. • Data Scientist: Uses advanced statistics and machine learning to build predictive models and algorithms. • Data Engineer: Builds pipelines, manages data warehousing, and handles ETL (extract, transform, load) processes. • Data Architect: Designs overall database systems and sets security access controls.
